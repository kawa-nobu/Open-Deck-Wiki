# トラブルシューティング（拡張機能版）

拡張機能版でよく起こる問題と解決方法をまとめました。  
「おかしいな？」と思ったらまずここを確認してみてください。

---

## Open-Deck が起動しない

### 確認ポイント(1)：URL が正しいか

起動用の URL は以下の通りです。スペルを確認してください。

```
https://x.com/run-opdeck
```

### 確認ポイント(2)：拡張機能が有効になっているか

ブラウザの拡張機能管理画面で Open-Deck のトグルがオンになっているか確認します。

- **Chrome・Brave・Edge：** アドレスバーに `chrome://extensions/` と入力
- **Firefox：** アドレスバーに `about:addons` と入力

### 確認ポイント(3)：ブラウザを再起動する

拡張機能のインストール直後やアップデート後は、ブラウザを一度完全に閉じて再起動することで解消する場合があります。

---

## カラムが真っ白になる・表示されない

F5キーやブラウザの更新ボタンを使用し、タブを再読み込みしましょう。

---

## 「プロファイルデータが壊れています」と表示された

拡張機能のアップデート時や予期しない終了後に稀に発生します。

- **「OK」を押す** → データを初期化してクリーンな状態に戻します（おすすめ）
- **「キャンセル」を押す** → 初期化せずに続行します（動作が不安定になる可能性があります）

---

## タイムラインの自動更新が止まった

以下を順に確認してください。

1. **API 制限に達していないか確認する**  
   サイドバーの数字が 0% に近づいていたら制限です。回復まで待ちましょう。

2. **自動更新の設定が残っているか確認する**  
   カラム設定（歯車アイコン）を開き、「自動更新」がオンになっているか確認します。

3. **ページをリロードする**  
   まれに長時間使用しているとリロードが必要になることがあります。

:::tip[ブラウザ側の省エネルギー機能で更新が止まる場合があります！]
Chromium系のブラウザ(Chrome / Brave / Edge)などでは、  
省エネルギー機能として、自動で自動更新をブラウザ側が制限することがあります。
Open-Deckではこの問題への対処に取り組んでいます。

問題が顕著に現れる場合は、[デスクトップアプリ版](/docs/desktop/overview)の使用をご検討ください。

:::

---

## Firefox でツイート種類の表示モードが動作しない

Firefox ESR 115 以前の既知の問題です。  
最新の通常版 Firefox に切り替えると解決します。詳しくは [拡張機能版について](./overview) をご覧ください。

## 開発者向けオプション: デバッグメニューの使い方

デバッグメニューは問題の診断・リセット用の特別なメニューです。

**※開発者でない場合は、初期化等のトラブルを避けるため触らないことを強く推奨します！**

**開き方：** サイドバーの Open-Deck ロゴ下のバージョン部分を何度か連続でクリックすることで、  
「デバッグメニューが利用できます！」というメッセージが表示されてメニューが現れます。

### メニュー項目

| 項目 | 説明 |
|---|---|
| **初期化** | **即座に**すべての設定・プロファイルをリセットして再起動します。**元に戻せないため最終手段として使用してください** |
| **プロファイルローダー** | 保存されているプロファイルデータを確認・デバッグします |
| **dNR_Reload** | ネットワークのリクエストルール（declarativeNetRequest）を再読み込みします |
| **拡張機能再読み込み** | 拡張機能全体をリフレッシュします |
