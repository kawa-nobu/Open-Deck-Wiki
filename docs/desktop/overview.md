# デスクトップ版について

<img src="/Open-Deck-Wiki/img/screenshot/desktop.png" width="800" />

Open-Deck Desktop は、拡張機能版 Open-Deck をベースに作られた単独のアプリケーションです。  
ブラウザの制約を受けないため、安定性が向上しているほか、拡張機能版では実現できなかった機能が多数搭載されています。


---

## デスクトップ版でできること

### 拡張機能版との違い

デスクトップ版では共通機能に加えて、以下の独自機能が使えます。

| 機能 | 説明 |
|---|---|
| **複数アカウントの同時表示** | アカウントごとにセッションを作り、カラムで使い分けられます |
| **他 SNS カラム** | Misskey.io・Bluesky のタイムラインをカラムに追加できます（試験実装） |
| **UI カラーモード設定** | システム / ライト / ダーク から外観テーマを選べます |
| **閉じるボタンの最小化割り当て** | ウィンドウの × ボタンでアプリを終了せず最小化できます |
| **プロモーション(広告)非表示** | タイムライ上の広告を非表示にできます |

---

## こんな方におすすめ

- **複数の X アカウントを同時に監視したい**  
  → メインアカウントとサブアカウントを並べて表示できます

- **Misskey や Bluesky も Open-Deck で管理したい**  
  → 他の SNS のタイムラインも同じ画面にまとめられます（試験実装）

- **広告なしでタイムラインを見たい**  
  → プロモーション非表示機能でスッキリした表示になります

- **常駐アプリとして使いたい**  
  → 閉じるボタンを最小化に割り当てて、バックグラウンドで常時動かせます

---

## デスクトップ版の構成

デスクトップ版は拡張機能版と同様の仕組みを採用しており、
公式Webクライアントを呼び出して使用し、Open-Deck側ではAPIを直接扱っていません。

このため基本的な操作感は拡張機能版とほぼ同じです。  
共通機能のドキュメントも参考にしてください。

:::note
デスクトップ版固有の機能については、このセクション内の各ページで説明しています。  
共通機能（カラム操作・プロファイル・自動更新など）は [共通機能](/docs/category/共通機能) をご覧ください。
:::
