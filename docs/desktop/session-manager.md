# 複数アカウント（セッション管理）

アカウントセッション機能はデスクトップ版 Open-Deck が持つ大きな機能の一つです。  
複数の SNS アカウントを同時にログインしたまま維持し、カラムごとに使うアカウントを切り替えられます。

---

## セッションって何？

通常のブラウザにインストールされた拡張機能版 Open-Deck では、ブラウザ側の仕様により複数のアカウントを同時に使用できません。  
そこで、デスクトップアプリ版 Open-Deck では「アカウントセッション」という仕組みを用意し、  
**各カラムごとに独立したログイン状態を保持できるように実装しました**。

たとえば X のアカウントを 3 つ持っている場合、3 つそれぞれのセッションを作ることで、  
**3 つのタイムラインを同時に並べて表示**できます。

<img src="/Open-Deck-Wiki/img/screenshot/account_sessions_column.png" width="800" />

このスクリーンショットのように、複数のアカウントに分かれたカラムの作成が可能です。

:::tip[アカウントセッション機能はTwitter(X)以外のSNSにも対応しています！]
- Twitter (X)
- Misskey
- Bluesky
:::

---

## セッションマネージャーを開く

<img src="/Open-Deck-Wiki/img/screenshot/account_session_manager.png" width="500" />

アプリのメニュー、またはサイドバーから **「アカウントセッションマネージャー」** を開きます。

---

## 新しいセッション（アカウント）を追加する

<img src="/Open-Deck-Wiki/img/screenshot/create_session.gif" width="500" />

1. セッションマネージャーで追加したい SNS（例：X / Misskey / Bluesky） の **「新規追加」** 欄のテキストボックスをクリックします
2. セッション名を入力します（例：`サブ垢A`・`仕事用`）
3. **「追加」** ボタンをクリックします

:::warning[使えない名前があります]
セッション名に **「default」「デフォルト」** は使用できません（システム予約名）。  
別の名前を付けてください。
:::

---

## カラムにセッションを割り当てる

<img src="/Open-Deck-Wiki/img/screenshot/switch_session.gif" width="500" />

セッションを作成しただけでは、カラムには反映されません。  
カラムの設定から、どのセッション（アカウント）を使うか指定する必要があります。

1. 設定したいカラムのヘッダーにある **セッション切り替えアイコン( <img src="/Open-Deck-Wiki/img/opd_icons/select_session.svg" width="16" /> )** をクリックします
2. 画面に表示された「アカウントセッション」から使用したいセッションを選択します
3. 設定を閉じると、選択したアカウントに切り替わり表示されます

---

## セッションを削除する

<img src="/Open-Deck-Wiki/img/screenshot/delete_session.gif" width="500" />

1. セッションマネージャーで削除したいセッションの **「削除」** ボタンをクリックします
2. 確認ダイアログで **「OK」** を押します

:::warning[削除できない場合]
現在いずれかのカラムで **使用中のセッション**は削除できません。  
削除するには、先にそのセッションを使っているカラムを閉じるか、別のセッションに変更してください。
:::
