# 他 SNS カラム

デスクトップ版では、X (Twitter) 以外の SNS のタイムラインもカラムとして表示できます。  
現在は **試験実装** 段階で、Misskey.io と Bluesky に対応しています。

:::note[試験実装について]
他 SNS カラムは現在、試作段階の機能です。  
動作が不安定だったり、一部の機能が使えない場合があります。ご了承ください。
:::

---

## 対応している SNS
- [Misskey](https://misskey.io/)
- [Bluesky](https://bsky.app/)
---

## 他 SNS カラムを追加する手順

<img src="/Open-Deck-Wiki/img/screenshot/add_other_sns.gif" width="800" />

### ステップ 1：カラムを追加する

サイドバーに Misskey・Bluesky のカラム追加ボタンがあります。  
クリックするとカラムが追加されます。

### ステップ 2：(**必要であれば**)カラムにセッションを割り当てる

**切り替え方についての詳しい情報は複数アカウント機能の「[カラムにセッションを割り当てる](./session-manager.md#カラムにセッションを割り当てる)」をご参照ください。**

1. 設定したいカラムのヘッダーにある **セッション切り替えアイコン( <img src="/Open-Deck-Wiki/img/opd_icons/select_session.svg" width="16" /> )** をクリックします
2. 画面に表示された「アカウントセッション」から使用したいセッションを選択します
3. 設定を閉じると、選択したアカウントに切り替わり表示されます
