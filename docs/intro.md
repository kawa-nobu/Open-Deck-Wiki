# Open-Deck へようこそ

## Open-Deck って何？

X (旧 Twitter) を使っていると、こんな場面はありませんか？

- タイムラインを見ながら通知も確認したい
- 複数のキーワードで検索結果を並べてチェックしたい
- DM を見ながら投稿もしたい

**Open-Deck** は、そんな「もっと効率よく X を使いたい」という気持ちに応えるツールです。  
画面を **カラム（縦長のパネル）** に分割して、タイムライン・通知・検索などを横並びで同時に表示できます。

:::tip[カラムって？]
「カラム（column）」とは「列」という意味です。  
Open-Deck では、タイムラインや通知などのコンテンツ(画面)を 1 枚のカードのように表示し、  
それを横に何枚でも並べて使える仕組みになっています。
:::

---

## Open-Deck には 2 つのタイプがある

Open-Deck には **ブラウザの拡張機能版** と **デスクトップアプリ版** の 2 種類があります。  
どちらも基本的な使い勝手は同じですが、デスクトップ版にはさらに便利な機能が追加されています。

### どちらを選べば良いですか？

| | 拡張機能版 | デスクトップ版 |
|---|---|---|
| **インストールの手軽さ** | Webストアからワンクリック | アプリを手動でダウンロード |
| **複数アカウントの同時表示** | <i class="fa-solid fa-minus"></i> | <i class="fa-solid fa-check" style={{color: 'rgb(0, 195, 135)'}}></i> |
| **Misskey / Bluesky 等の他SNS活用** | <i class="fa-solid fa-minus"></i> | <i class="fa-solid fa-check" style={{color: 'rgb(0, 195, 135)'}}></i>（試験実装） |
| **広告の非表示** | <i class="fa-solid fa-minus"></i> ([CSLT](https://chrome.google.com/webstore/detail/clean-spam-link-tweet/bniigfmpkmcabajbkelbmphoelijoang)の導入で可能) | <i class="fa-solid fa-check" style={{color: 'rgb(0, 195, 135)'}}></i> |
| **対応ブラウザ** | Chrome・Brave・Edge・Firefox | アプリ単独で動作(WIndows10-11 / Linux) |

:::tip[まずは拡張機能版から試してみよう]
Open-Deck が初めてなら、**拡張機能版**から始めるのがおすすめです。  
[Chrome Web Store](https://chromewebstore.google.com/detail/open-deck/gmkadaeibmhchpimnfplodelecmogdic) から 1 クリックで導入でき、すぐに使い始められます。  
複数アカウントを使いたくなったら、デスクトップ版に切り替えましょう。
:::

## 機能一覧

### 共通機能（すべてのタイプで使えます）
#### カラム
| 機能 | 説明 |
|---|---|
| **タイムラインカラム** | フォロー中のタイムラインを表示します。**(※非記憶カラム)** |
| **通知カラム** | いいね・リプライ・フォローなどの通知を表示します **(※非記憶カラム)** |
| **Explore カラム** | DM・リスト・検索・トレンドなど自由に設定できるカラムです **(※ユニバーサルカラム)** |
| **Post カラム** | 投稿画面を常時表示できます **(ポスト専用カラム)** |

:::tip[非記憶カラムとは]
**非記憶カラム**とは、
表示画面の記憶をせず次回起動時に  
初期の画面(TimeLineカラムの場合はTimeLineカラムの初期)へ戻るカラムのことです。
次回起動時にタイムラインや通知を常時表示させたい場合に使用ください。

また、**次回以降も同じ画面を表示させたい場合はExploreカラム(**ユニバーサルカラム**)** をご使用ください。
:::
:::tip[ユニバーサルカラムとは]
**ユニバーサルカラム**とは別称で**Exploreカラム**や**万能カラム**とも呼び、  
最後に表示された画面が次回起動時に同じように表示されます。  
また、次回起動時に表示させる画面を登録できる、**ピン留め**機能等が利用可能なカラムです。

これらの機能を使用することで、あなたオリジナルの専用カラムを作成できます。

**DMやリストなど固定化が必要なカラムは、このユニバーサルカラムを利用しましょう！**
:::

#### 機能
| 機能 | 説明 |
|---|---|
| **カラム無制限追加** | 画面の広さが許す限り何枚でも追加できます |
| **2 段表示** | カラムを上下 2 列に並べてより多くの情報を表示できます |
| **自動更新** | 指定した秒数ごとに自動でリロードします |
| **カラム幅のカスタマイズ** | 小・中・大・カスタムから選んで調整できます |
| **プロファイル管理** | カラム構成を名前をつけて無制限に保存・切り替えできます |
| **テキスト校正** | 投稿前に誤字・表現の揺れを自動チェックします（試作版） |
| **メディアビューワー** | 画像や動画をいっぱい表示してダウンロードできます |

### デスクトップ版のみの機能

| 機能 | 説明 |
|---|---|
| **複数アカウント（セッション機能）** | アカウントごとにセッションを作り、カラムで使い分けられます |
| **他 SNS カラム** | Misskey.io・Bluesky のカラムを追加できます（試験実装） |
| **UI カラーモード** | システム / ライト / ダーク から選択できます |
| **閉じるボタンの最小化割り当て** | × ボタンでアプリを終了せずに最小化できます |
| **プロモーション非表示** | タイムラインの広告ポストを非表示にできます |

### デスクトップ版の対応 OS

Windows・Linux で動作します。
**(macOS向けに近日公開予定！)**

:::warning[Firefox ESR をお使いの方へ]
Firefox ESR 115（ESR 版ベース含む）では **「ツイート種類の表示モード」** が動作しません。  
Open-Deck が使用している機能が ESR版のバージョン115には搭載されていないためです。  
最新の通常版 Firefox か 最新版の Firefox ESR への切り替えをおすすめします。
:::
