# プロファイル管理

<img src="/Open-Deck-Wiki/img/screenshot/profile_tool_bar.png" height="300" />

プロファイルとは **カラムの構成と各設定をまとめて保存したもの**です。  
「仕事中はこのレイアウト」「趣味の時間はこのレイアウト」というように、シーンに応じてワンクリックで切り替えられます。

---

## プロファイルに保存される情報

プロファイルには以下の情報がすべて含まれます。

- 配置されているカラムの種類・順序
- 各カラムの表示モード・カラム幅・自動更新設定
- Explore カラムのピン留め先 URL
- 1 段 / 2 段表示の状態

:::tip[プロファイルは無制限に作れます]
いくつでも保存できます。使わなくなったプロファイルは削除して整理しましょう。
:::

---

## プロファイルを保存する

1. 保存したいカラム構成を画面に配置します
2. サイドバー下部の **プロファイル保存アイコン（ <img src="/Open-Deck-Wiki/img/opd_icons/profile_save.svg" width="16" /> ）** をクリックします
3. 「現在の構成でプロファイルを作成します」のダイアログで **「OK」** を押します

現在のカラム構成が新しいプロファイルとして追加されます。  
プロファイルには P0・P1・P2 … と番号が自動で振られます。

---

## プロファイルを切り替える
プロファイルの切り替えは非常に簡単に行なえます。

1. サイドバーに表示されている **P0・P1・P2 …** ボタンをクリック
2. 確認ダイアログでプロファイルのカラム構成が表示されます
3. 確認が済んだら、確認ダイアログの **「OK」** を押します

:::note[切り替え前に構成を保存しておきましょう]
プロファイルを切り替えると、現在のカラム配置が失われます（保存していない場合）。  
大切なレイアウトは切り替える前にかならず保存してください。
:::

---

## プロファイルを削除する

1. サイドバーの **プロファイル削除アイコン（ <img src="/Open-Deck-Wiki/img/opd_icons/profile_delete.svg" width="16" /> ）** をクリックします
2. 「削除するプロファイル番号を半角入力」のダイアログが開くので、削除したい番号を入力します
3. 確認ダイアログで **「OK」** を押します

:::warning[削除前に確認を]
- **現在表示中のプロファイルは削除できません**。別のプロファイルに切り替えてから削除してください
- 削除後は残ったプロファイルの番号が **0 から振り直されます**  
  （例：P0・P1・P2 のうち P1 を削除すると、元の P2 が P1 になります）
:::
