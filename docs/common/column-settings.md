# カラムの設定

<img src="/Open-Deck-Wiki/img/screenshot/column_settings.png" width="400" />

各カラムには個別の設定があります。  
画像の設定項目はExploreカラムです。  

カラムヘッダーの **歯車アイコン** をクリックすると設定画面が開きます。

---

## 表示モード

<img src="/Open-Deck-Wiki/img/screenshot/column_dsp_settings.png" width="400" />

Timeline カラムや Explore カラム（検索ページ）で、表示するポストの種類を絞り込めます。

### モード一覧

| モード | 内容 | 引用ポストの扱い |
|---|---|---|
| **すべて**（デフォルト） | すべてのポストを表示します | すべて表示します |
| **テキストのみ（引用なし）** | 画像・動画のないテキストだけのポストを表示します | 中身に関係なく非表示にします |
| **画像・動画付のみ（引用なし）** | 画像・動画が添付されたポストだけを表示します | 中身に関係なく非表示にします |
| **テキストのみ（引用あり）** | テキストだけのポストを、引用ポストも含めて表示します | 投稿本体・引用元のどちらにも画像・動画がなければ表示します |
| **画像・動画付のみ（引用あり）** | 画像・動画付きのポストを、引用ポストも含めて表示します | 投稿本体・引用元のどちらかに画像・動画があれば表示します |

:::tip[「引用なし」と「引用あり」の違い]
「引用なし」のモードでは、引用ポストは中身に関係なくすべて非表示になります。  
引用ポストも絞り込みの対象にしたい場合は、「引用あり」のモードを選んでください。
:::

:::note[記事の扱い]
記事は、カバー画像の有無に関係なく「テキストのみ」として扱います。
:::

### 投稿の種類ごとの表示

| 投稿の種類 | テキストのみ（引用なし） | 画像・動画付のみ（引用なし） | テキストのみ（引用あり） | 画像・動画付のみ（引用あり） |
|---|---|---|---|---|
| テキストのみの通常投稿 | 表示 | 非表示 | 表示 | 非表示 |
| 画像・動画付きの通常投稿 | 非表示 | 表示 | 非表示 | 表示 |
| テキストのみの引用（引用元もテキストのみ） | 非表示 | 非表示 | 表示 | 非表示 |
| 引用元にだけ画像・動画がある投稿 | 非表示 | 非表示 | 非表示 | 表示 |
| 画像・動画がある引用投稿 | 非表示 | 非表示 | 非表示 | 表示 |
| 記事の投稿（本文・カバー画像の有無を問わない） | 表示 | 非表示 | 表示 | 非表示 |
| 記事を引用した投稿 | 非表示 | 非表示 | 表示 | 非表示 |
| 画像・動画付きで記事を引用した投稿 | 非表示 | 非表示 | 非表示 | 表示 |

:::tip[「画像・動画付のみ」の活用例]
フォロワーのユーザーページでイラストや写真だけをまとめてチェックしたい時に活用できます。
:::

## カラム幅

<img src="/Open-Deck-Wiki/img/screenshot/column_size_settings.png" width="400" />

カラムの横幅を変更できます。大きい画面でも小さい画面でも、使いやすいサイズに調整しましょう。

| 設定値 | 目安の幅 | こんな人向け |
|---|---|---|
| **小** | 約 15rem | たくさんのカラムを並べたい |
| **中** | 約 20rem | バランスよく表示したい |
| **大**（デフォルト） | 約 30rem | ゆったり読みたい |
| **カスタム** | 自由に指定 | 細かく調整したい |

### **カスタム設定の手順**

<img src="/Open-Deck-Wiki/img/screenshot/column_custom_size.gif" width="400" />

1. 「カスタム」を選んで **「カスタム設定」** ボタンをクリックします
2. ダイアログに rem 値を半角数字で入力します（**11 以上**の値を入力してください）
3. **「OK」** を押して適用します

## 自動更新

カラムの内容を自動的に再読み込みする機能です。詳しい設定方法と API 制限の注意点は  
→ [自動更新の設定](./auto-reload) で説明しています。

## 設定を閉じる

設定が終わったら **「設定を閉じる」** ボタンをクリックします。  
設定はカラムごとに保存され、プロファイルにも含まれます。
